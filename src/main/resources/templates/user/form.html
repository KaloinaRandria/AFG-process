Utilisateurs
Circuit de validation : votre saisie crée une demande. Le compte ne sera qu'après validation par un IT_CHECKER (une autre personne que vous).

Le mot de passe est celui de l'Active Directory : le mail doit correspondre au compte AD du collaborateur.

Rôles

Sans rôle, le compte est un collaborateur : il consulte les procédures et passe les quiz.
